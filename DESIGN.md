# Dirección visual

Reading this as: portfolio personal interactivo para desarrolladores, con lenguaje visual PS Vita LiveArea 3D, diales ENERGY 3 / RHYTHM 2 / MOTION 2.

## Identidad

- La consola PS Vita es el foco principal porque convierte el portfolio en una experiencia reconocible, no en una landing genérica.
- La paleta base usa navy profundo y azul cian para evocar una pantalla retro iluminada. El morado queda como acento de interacción y perfil.
- Las burbujas usan variaciones de color para distinguir destinos del sistema. No representan métricas ni estados falsos.
- `Rajdhani` se usa en la interfaz de dispositivo por su lectura compacta y carácter de hardware. `Ubuntu` se usa en el contenido para mantener legibilidad.
- Las tarjetas y paneles agrupan contenido real del portfolio: perfil, proyectos, habilidades y contacto. No se añaden secciones de plantilla.
- Los gradientes modelan la profundidad de la pantalla y el acabado glossy de las burbujas. Las sombras solo marcan separación entre superficies.
- El movimiento comunica interacción: inclinación 3D al arrastrar, transición al abrir una app y feedback de hover. No se usa movimiento ambiental continuo.

## Estados y accesibilidad

- Cada vista de datos debe distinguir carga, vacío y error con texto visible.
- Los controles conservan un área táctil mínima de 44 px aunque la composición visual se escale en móvil.
- Las ventanas de app se pueden cerrar con el botón visible o con Escape y devuelven el foco a su lanzador.
